## 용어를 사용할 때

| 용어 | 이 책의 뜻 | 주의 |
| --- | --- | --- |
| 에이전틱 커머스 | AI가 사람의 의도를 받아 상품 발견, 선택, 거래 실행의 일부에 관여하는 방식 | 완전 자율 구매를 뜻하지 않음 |
| ACP | OpenAI·Stripe가 추진한 Agentic Commerce Protocol | 다른 회사의 UCP와 동일한 규격이 아님 |
| UCP | Google이 여러 기업과 제안한 Universal Commerce Protocol | 모든 판매자가 이미 연결된 것은 아님 |
| AP2 | Agent Payments Protocol | 2026년 FIDO Alliance로 기증 발표 |
| TAP | Visa Trusted Agent Protocol | 에이전트 신원 확인을 다루며 결제 전체를 뜻하지 않음 |
| 시나리오 | 확인된 사실을 바탕으로 가정한 2027년 가능한 모습 | 실현을 보장하지 않음 |

2027년 변화의 속도, 국내 서비스 도입 시점, 프로토콜 간 수렴 여부는 **현재 확인된 사실이 아닙니다**. 새 발표가 나올 때마다 이 문서를 먼저 갱신합니다.
